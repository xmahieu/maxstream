MaxStream IPTV

Application IPTV gratuite pour Kodi 21 « Omega » : TV en direct, films, séries et replay.

Télécharger le dépôt Kodi (zip) MaxStream 2.3.2 seul (zip)

Le dépôt installe MaxStream et le garde à jour automatiquement. Free download — English below each step.

Installer dans Kodi

Méthode 1 · Ajouter la source

  1. Paramètres › Système › Extensions : activer Sources inconnues.
  2. Paramètres › Gestionnaire de fichiers › Ajouter une source : https://maxstreamkodi-cyber.github.io/maxstream/ et nommez-la maxstream.
  3. Extensions › Installer depuis un fichier zip › maxstream › repository.maxstream-1.0.1.zip.
  4. Extensions › Installer depuis un dépôt › MaxStream Repository › Extensions de programmes › MaxStream IPTV.

Add https://maxstreamkodi-cyber.github.io/maxstream/ as a file source, install the repository zip, then install MaxStream IPTV from it.

Méthode 2 · Fichier zip

  1. Téléchargez le dépôt (bouton ci-dessus) sur l'appareil Kodi ou une clé USB.
  2. Activez Sources inconnues, puis Extensions › Installer depuis un fichier zip.
  3. Installez MaxStream IPTV depuis MaxStream Repository.

MaxStream s'ouvre dans Extensions › Programmes. Ajoutez votre compte Xtream Codes ou votre liste M3U au premier lancement.

Ce que fait MaxStream

  • Comptes Xtream Codes, URL M3U et fichiers M3U
  • TV en direct avec aperçu vidéo et guide TV
  • Films et séries en affiches, reprise de lecture
  • Replay (catch-up) sur les chaînes compatibles
  • Favoris, recherche, plusieurs listes
  • Contrôle parental par code PIN
  • Reconnexion automatique quand le flux bloque
  • Chaînes aussi dans le menu TV de Kodi
